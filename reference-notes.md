# External reference notes

## Rollbux sign-up reference
Source repository: https://github.com/Sotarium/rollbux
Reference file: `server/signup.html`

The reference uses a centered dark page with a bold italic wordmark, a `Create account` heading, a dark form card, username/email mode buttons, identifier input, password input with a 5+ character hint, bright lime primary action, validation copy, and a login link. The app implementation recreates the interaction pattern with Sotarium branding and local demo state only.

## Microsoft Store app reference
Source listing: https://apps.microsoft.com/detail/9PDXFBWZNTNJ?hl=en-us&gl=CA&ocid=pdpshare

Listing title: `Cue by Manus - Free download and install on Windows`.
Description: `Your personal agents, on Cue. Whatever life brings, Cue is here to help you handle it.`

The official Store screenshots show a light chat-first Windows workspace: a left conversation rail, persistent personal agents, colorful character avatars, chat bubbles, agent handoffs/tool cards, and memory updates. The Sotarium workspace uses these interaction and layout cues while keeping original implementation and Sotarium naming.
